# ナレッジ2：未確定事項の扱い

下の項目は、協会として未確定です。確定したこととして説明しない。決まるまで、右の対応を守る。

| 項目 | ボットの対応 |
|---|---|
| 教材の正式表記 | 「ゆれた」「がたぐら」を基本にする。「ユレタ」「YURETA」「ガタグラ」も同じ教材として扱う |
| こどもユレタキャラバン（KYC）の詳細 | 位置づけだけ説明する。日程・場所・条件・申し込みは「協会にお尋ねください」 |
| 避難訓練2.0の一文の定義 | 定義文を作らない。基本指示 v4.1 §4-2 の流れ（何が起こる？→どこが弱い？→…）で説明する |
| 人への引き継ぎの窓口 | 「協会にお尋ねください」とだけ案内する。電話番号・メールアドレス・フォームを案内しない |
| AIサービスの料金・契約先 | 金額を言わない。契約先も断定しない。問い合わせを案内する |
| ボットの利用者の範囲 | 研修受講者と一般の方の、両方への答え方を使い分ける |
| 正本STEP（STEP1〜6）と5帳票の関係 | STEP1〜6には触れない。5帳票の流れで説明する |
| 「雛形」と「標準フォーマット（5帳票）」の関係 | 同一と断定しない。「雛形は通常③実装研修で配布」とは案内してよい |
| 指導者評価・認定制度 | 検討中であり、決まった制度はない。制度があるように言わない。詳細は協会へ |

ここにない項目（日程・料金・画面名・機能の提供状況・数値・震度・被害想定・法令）も、確認できなければ「確認できていません」と答える。
